# Mutual Fund Analytics Platform

## Overview

The Mutual Fund Analytics Platform is an end-to-end data analytics project developed during my Data Analyst Internship at Bluestock Fintech. The project integrates multiple publicly available mutual fund datasets, processes them through an automated ETL pipeline, stores the cleaned data in a SQLite database, performs financial and risk analysis, and presents insights through an interactive Power BI dashboard.

## Features

- Automated ETL Pipeline
- Data Cleaning and Validation
- SQLite Relational Database
- Exploratory Data Analysis (EDA)
- Performance Analytics
- Advanced Risk Metrics
- Interactive Power BI Dashboard



## Tech Stack

- Python
- Pandas
- NumPy
- SQLite
- SQLAlchemy
- Jupyter Notebook
- Power BI
- Matplotlib



## Workflow

1. Collect mutual fund datasets from public sources.
2. Perform ETL using Python.
3. Store processed data in SQLite.
4. Conduct Exploratory Data Analysis.
5. Calculate financial performance and risk metrics.
6. Develop an interactive Power BI dashboard.
7. Generate business insights and reports.



## Financial Metrics

- CAGR
- Sharpe Ratio
- Alpha
- Beta
- Tracking Error
- Maximum Drawdown
- Value at Risk (VaR)
- Conditional Value at Risk (CVaR)



## Dashboard

The Power BI dashboard contains four interactive pages:

- Industry Overview
- Fund Performance
- Investor Analytics
- SIP & Market Trends
